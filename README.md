# Sistema de Gestión de Productos 📦

Repositorio correspondiente al taller práctico de programación, el cual implementa un sistema de gestión de inventarios con operaciones CRUD completas, validaciones de negocio y arquitectura orientada a objetos.

---

## 🚀 Cómo ejecutar el proyecto usando GitHub Codespaces

GitHub Codespaces te permite ejecutar este entorno de desarrollo directamente en la nube en cuestión de segundos, sin necesidad de instalar configuraciones locales complejas. Sigue estos pasos para acceder y probar la aplicación:

### Paso 1: Crear el Codespace
1. Ve a la página principal de este repositorio en GitHub.
2. Haz clic en el botón verde **`<> Code`** situado en la parte superior derecha.
3. Selecciona la pestaña **Codespaces**.
4. Haz clic en el botón **`Create codespace on main`**. Esto iniciará un entorno limpio en tu navegador web.

### Paso 2: Ejecutar el programa en la terminal
Una vez que el entorno de Codespaces haya terminado de cargar la interfaz:
1. Si te pide descargar la extension de Java descargarla.
2. Cuando ya la tengas descargada, puedes darle run al codigo.
